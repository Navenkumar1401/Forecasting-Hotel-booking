# Data-Driven Insights and Prediction Models for Hotel Booking

## 📊 Project Overview
This project explores **hotel booking data** using **Machine Learning techniques**.  
The notebook analyzes booking patterns, customer behavior, and cancellation trends, and then builds **predictive models** to forecast cancellations and optimize hotel management decisions.  

---

## 🗂️ Features
- **Exploratory Data Analysis (EDA)**
  - Booking patterns by month, market segment, and lead time
  - Cancellation trends and key influencing factors
  - Customer demographics and booking preferences
- **Data Preprocessing**
  - Handling missing values
  - Feature encoding & scaling
  - Train-test splitting
- **Machine Learning Models**
  - Logistic Regression
  - Decision Tree / Random Forest
  - Gradient Boosting / XGBoost
- **Evaluation**
  - Accuracy, Precision, Recall, F1-Score
  - Confusion Matrix & ROC Curve
- **Insights**
  - Key drivers of cancellations
  - Business recommendations

---

## 📁 Repository Structure
